# LinkedIn UI Clone 💼

A pixel-conscious LinkedIn-inspired mobile interface built with **Flutter** and **Dart**. 
This project focuses on UI/UX, clean code structure, and reusable components.

## ✨ Features
- Sign in, sign up, and forgot password flows
- Home feed with post cards
- Dedicated post screen
- Reusable custom widgets
- Modular, scalable folder structure

## 📁 Project Structure

lib/
├── data/        # Dummy/static data and data sources
├── home/        # Home feed and post screens
│   ├── home_screen.dart
│   └── post_screen.dart
├── models/      # Data models (posts, users, etc.)
├── screens/     # App screens
│   ├── signin_screens/
│   │   ├── signin_screen.dart
│   │   └── forget_password.dart
│   └── signup_screens/
├── widgets/     # Reusable UI components
└── main.dart    # App entry point

## 🛠 Tech Stack
- Flutter
- Dart

## 🚀 Getting Started
1. Clone the repo
   git clone https://github.com/Aneesa-Rani/linked_in_ui.git
2. Install dependencies
   flutter pub get
3. Run the app
   flutter run
